# LJ seven-vacancy system

This experiment is part of [GML4MS](../../README.md), the companion code for
*Generative marginal learning for finite-size molecular simulation with
application to stress calculation* ([arXiv:2610.25105](https://arxiv.org/abs/2610.25105)).

From this directory, generate independent MD, preprocess the training data,
train force/denoising/joint models and sample configurations.

See [the full LJ workflow](../../docs/lj.md) and the
[root setup instructions](../../README.md#environment).
